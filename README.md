## 📘 Descripción general del sistema
Este proyecto corresponde a la actividad formativa de la Semana 4 de la asignatura **Desarrollo Orientado a Objetos I**. Se trata de un sistema desarrollado en Java cuyo objetivo es modelar y gestionar los tours ofrecidos por la agencia **Llanquihue Tour**, leyendo los datos desde un archivo de texto plano (`.txt`) y almacenándolos en una colección dinámica del tipo `ArrayList`.

El proyecto aplica los principios fundamentales de la programación orientada a objetos, incluyendo encapsulamiento (atributos privados con getters y setters), composición y el uso de estructuras de datos dinámicas. Además, implementa operaciones básicas sobre la colección, tales como recorrido, búsqueda y filtrado por tipo de tour, con el fin de fortalecer la manipulación de estructuras dinámicas y el vínculo entre archivos externos y objetos en Java.

## 🧱 Estructura general del proyecto 
```plaintext
src/
├── model/          # Clases de dominio (Tour.java)
├── data/           # Clases para la carga y lectura de archivos .txt (GestorDeTours.java)
├── ui/             # Clase principal con el método main (Main.java)
└── resources/      # Archivo de datos (DatosDeTours.txt)
````

## ⚙️ Instrucciones para clonar y ejecutar el proyecto


5. Sigue las instrucciones en consola o en la interfaz gráfica (si corresponde).
